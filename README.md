# AskPIP Core

## Purpose

Welcome to **AskPIP Core**.

AskPIP Core is the authoritative repository for the AskPIP platform.

It contains the knowledge, documentation, software, standards and supporting assets required to develop, operate and maintain the AskPIP ecosystem.

AskPIP Core is the authoritative single source of truth for the AskPIP project.

Every approved change to AskPIP begins here.

---

## Vision

AskPIP exists to help gardeners grow in understanding of each individual plant through its unique story, so they can care for it with confidence.

Core exists to preserve, organise and evolve the knowledge and systems that make that mission possible.

---

## Repository Principles

The repository is governed by the following principles.

- Truth before convenience.
- Evidence before opinion.
- Stewardship before speed.
- Simplicity before complexity.
- Every meaningful change is recorded.
- Approved knowledge is preserved.
- AI assists. Founders decide.

---

## Repository Contents

As AskPIP evolves, Core will become the home of:

- Knowledge Curation System (KCS)
- Research documentation
- Knowledge standards
- Founder documentation
- Application source code
- Website source code
- AI agent instructions
- Supporting assets
- Project documentation

---

## Working Philosophy

Core is intended to remain organised, understandable and maintainable.

Contributors should:

- understand before changing;
- minimise unnecessary complexity;
- preserve history;
- document significant decisions;
- avoid duplicate information;
- leave the repository in a better state than they found it.

---

## Change Management

All meaningful changes should be:

- intentional;
- documented;
- traceable;
- reviewable;
- reversible where practical.

---

## Governance

The Founders are the custodians of the AskPIP platform and its Core repository.

Artificial intelligence is used to assist research, documentation, software development and repository maintenance.

AI does not become the authority.

The Founders remain responsible for all final decisions.

---

## Status

This repository is under active development.

Its structure, documentation and software will continue to evolve as AskPIP grows.

Every improvement to AskPIP begins with improving Core.
