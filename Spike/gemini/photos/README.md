# Sample photo goes here

Put a photo of a rose stem here named `sample-stem.jpg` (or pass a different
path as the first argument to `run-spike.mjs`).

Ideally a stem showing what a beginner gardener might genuinely wonder about
— e.g. a stem that looks darker/drier than its neighbours, the kind of thing
the dead-wood observation in the app is proposing to check. It doesn't need
to be a "perfect" textbook photo — a slightly ambiguous one is actually a
better test of whether the model stays honest about uncertainty.

This folder is gitignored — nothing you put here gets committed.
