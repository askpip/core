# PKR Submission Package — Source PKRs (Dead vs. Living Wood + Dormancy Gate)

**Status of this package:** Published. All 24 records reviewed and approved by the Founder 23 August 2026, based on a representative walkthrough of three records (PKR-SRC-000001, PKR-SRC-000006, PKR-SRC-000014) rather than a line-by-line read of all 24 — an intentional, lighter-scrutiny pass, since the purpose of this round was to test whether the Source PKR mechanism functions end-to-end, not to exhaustively audit 24 bibliographic records. Approved directly to Published in the same pass, per Founder direction — Source PKRs carry no dependency on any other PKR (PKR Standard §5.5), so unlike PKR-OBS-000001/PKR-DEC-000001/PKR-SGT-000001, nothing blocks these from completing the full Draft → Approved for Publication → Published lifecycle in one step. The two exclusions noted below (RHS "Shrub Roses"; the sporotrichosis fact sheet) were also confirmed correct.

**Why this package exists:** PKR Standard §4 lists "Supporting Source(s) — one or more Source PKR references" as a required Common Field for *every* PKR type. Four content-approved records — PKR-OBS-000001, PKR-DEC-000001, PKR-SGT-000001, and the five Definition PKRs — have been sitting Draft — Dependency-Blocked on this gap since their own approval, per Project_Backlog.md. This package builds the Source PKRs those first three records actually need (the five Definition PKRs are out of scope here — see Project_Backlog.md's open question on whether a Standards-level Definition PKR needs a Source PKR at all).

**Structural correction made before building these:** PKR Standard §5.5 previously stated a Source PKR "represents exactly one claim's source." Building this package would have required a separate, duplicate Source PKR for every Assessed Finding a document happens to support — for example, the American Rose Society's "Basic Pruning Principles" supports four different Assessed Findings at two different confidence levels in the dead-wood commission alone. That's the opposite of what a reusable, citable Source PKR is for. PKR Standard §5.5 and §4.2 were corrected to v0.09 first (Evidence Confidence on a Source PKR is now **Not Applicable**; **MIL Reference** is now **MIL References**, a list) — see that document's Revision Note for the full reasoning. No Source PKR was built under the old rule, so nothing needed to be redone.

**Scope of this package:** Every distinct source document actually cited by an Assessed Finding used in PKR-OBS-000001, PKR-DEC-000001, or PKR-SGT-000001. This is 13 documents plus 2 Founder observations from the dead-wood commission (FRD-BUSHROSE-DEADWOOD-01), and 9 documents from the dormancy commission (FRD-BUSHROSE-DORMANCY-01) — 24 records total. Two sources were checked and deliberately excluded: RHS "Rose Pruning: Shrub Roses" (dead-wood Source 2) contains no diagnostic guidance and isn't cited by any built PKR; the New York State Department of Health sporotrichosis fact sheet (dead-wood Source 14) supports AF-6, which isn't used by any PKR built yet — both excluded on the same principle: a Source PKR is built when something actually cites it, not spun up speculatively.

**IDs:** PKR-SRC-000001 through PKR-SRC-000024, assigned per KIT OM v0.4 §10.2 (plain sequential, no scope segment). Order follows the two commissions' own source numbering, dead-wood first, for traceability back to each FRD's §4 citation log — the ID sequence itself carries no meaning beyond creation order, per PKR Standard §6.

## 4. What This Reuse-by-Citation Design Actually Demonstrates

Two sources in this package are the clearest evidence for why the §5.5 correction was necessary before building any of this:

- **PKR-SRC-000006** (Clemson HGIC) is cited by four different Assessed Findings at two different confidence levels (High for pith colour and the cut-back rule; Moderate for dormant bud presence and escalating removal). One Source PKR, reused four times, each citation carrying its own confidence on the citing PKR — not four near-duplicate Source PKRs, and not one blended confidence figure sitting on the source itself.
- **PKR-SRC-000004** and **PKR-SRC-000016** are both "Oregon State University Extension Service" sources but are different articles entirely (different URLs, different commissions, different findings) — confirmed as genuinely distinct sources, not a duplicate that should have been merged into one record.

No source in this package needed to be split or merged once §5.5 was corrected — the citation-list design handled every case cleanly on the first pass.
