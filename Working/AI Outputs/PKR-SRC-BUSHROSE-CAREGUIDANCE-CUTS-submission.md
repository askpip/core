# PKR Submission Package — Source PKRs for Pruning Cuts, Tools and the One-Third Advisory (v1.0, Published)

Built per KIT OM Chapter 7 and PKR Standard §5.5 from `ARC-BUSHROSE-PRUNINGFRAMEWORK-01` (AF-21 to AF-31, AF-35, AF-38, AF-40) and `ARC-BUSHROSE-WEAKCONGESTED-01` (AF-18). Identities and web addresses come from the approved `Source_Register_Addendum_PRUNINGFRAMEWORK.md` (29 September 2026). Confidence levels were checked by script against the ARC, and each finding's source list was checked by script against the ARC's Source Register.

**Status: Published 29 September 2026** (approved by Shaphan in chat with `PKR-CGD-BUSHROSE-CUTS-01-submission.md`). Part B MIL References are applied in place in the earlier Source PKR files.

**Left out on purpose:** CSU Adams County (AF-40) is **not confirmed** in the approved register, so no Source PKR is built for it and the advisory doesn't cite it. AF-40 still rests on four confirmed sources.
