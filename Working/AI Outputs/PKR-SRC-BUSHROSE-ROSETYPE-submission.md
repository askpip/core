# PKR Submission Package — Source PKRs for the Rose-Type Suitability Gate (v1.0, Published)

Built per KIT Operations Manual Chapter 7 and PKR Standard §5.5 from `ARC-BUSHROSE-ROSETYPE-01` (sources as recorded in `FRD-BUSHROSE-ROSETYPE-01` §4.1, all accessed 27 September 2026). Only sources cited by a claim in PKR-SGT-000003 are built; sources cited solely by findings the gate does not use are not built yet, following the precedent in `PKR-SRC-submission.md`. No source cited only by the excluded AF-21/AF-22 is built.

**Published 29 September 2026.** Approved by Shaphan in chat, 29 September 2026, together with PKR-SGT-000003, on the condition that they contain only content from already-approved ARCs. That condition was checked before publishing (every MIL Reference matches the ARC's own Sources and confidence levels; see PKR-SGT-BUSHROSE-ROSETYPE-01-submission.md §6). v0.2 (29 Sep 2026): renumbered 000033–000048 after the gate dropped its unknown-type pass; the three sources cited only by AF-14, AF-15 or AF-23 were removed. Evidence Confidence is Not Applicable on every Source PKR (PKR Standard §5.5); the confidence shown against each MIL Reference belongs to the citing claim.
