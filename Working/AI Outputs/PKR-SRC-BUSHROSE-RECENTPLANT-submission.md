# PKR Submission Package — Source PKRs (Recently Planted Gate)

**Status of this package:** Published. All 8 records reviewed and approved by the Founder 23 August 2026, by representative walkthrough of three records (PKR-SRC-000027, PKR-SRC-000029, PKR-SRC-000030) rather than a full line-by-line read — the same lighter-touch pattern used for the first 24. Taken directly to Published in the same pass, since a Source PKR carries no dependency on any other PKR (PKR Standard §5.5). Built per PKR Standard v0.09 and KIT Operations Manual v0.4, following the same reuse-by-citation design as the first Source PKR package (`PKR-SRC-submission.md`, PKR-SRC-000001–000024, also Published).

**Scope:** Eight Source PKRs (PKR-SRC-000025–000032) for every source ARC-BUSHROSE-RECENTPLANT-01 actually operationalises — AF-1 (restraint period) and AF-2 (observable signals when planting date is unknown). Consistent with this project's established discipline, sources supporting AF-3 and AF-4 (documented in the ARC but explicitly not operationalised into gate logic, per Founder decision) are **not** built here — the same principle that excluded AF-6's source in the dead-wood commission and the Definition PKRs' sources: a Source PKR is built when something actually cites it as support, not speculatively. If AF-3 or AF-4 are operationalised in a future revision, their sources (Epic Gardening; David Austin Roses; Ask Extension/Oregon State University Extension; Homeguides/SFGate; Hunt County Master Gardeners) would be built then.

**Also not built here:** RHS, "Roses: Planting" (FRD-01 Source 3) — preserved in ARC-BUSHROSE-RECENTPLANT-01 §5 as unreconciled minority evidence, not as support for any operationalised finding.
