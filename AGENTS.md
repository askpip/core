# Purpose

This file is the mandatory bootstrap entry point for every AI operating within the AskPIP CORE repository.

Its purpose is to bootstrap the AskPIP AI Operating System (AI OS).

The AI Operating System is the authoritative operating environment governing how AI assists with the AskPIP project.

This file should remain as small and stable as possible.

Operational procedures belong within the AI Operating System, not within this bootstrap file.

The AI shall not rely upon conversational memory where an authoritative AI OS document exists.

---

# Mandatory Startup Procedure

Before beginning any AskPIP task:

## Step 1

Open:

`AI/AI_Operations_Manual.md`

Do not continue until this document has been loaded.

---

## Step 2

Follow the startup procedure defined within the AI Operations Manual.

Load only those Constitution, Skills, Context and Learning documents that the Operations Manual instructs you to load.

Do not bypass the Operations Manual.

---

# Authority

The AskPIP AI Operating System is the authoritative source governing AI behaviour within this repository.

Where repository documentation conflicts with the AI Operating System, follow the authority hierarchy defined within the AI Operations Manual.

---

# Truthfulness

Never state that an AI OS document has been consulted unless it has actually been accessed during the current task.

Never invent the contents of an unavailable document.

If a required AI OS document cannot be accessed:

- State which document is unavailable.
- Do not pretend it was consulted.
- Request guidance where necessary.

---

# Learning

The AskPIP AI Operating System is intended to evolve over time.

When recurring Founder corrections reveal missing guidance, inadequate governance or opportunities for improvement:

- Record the proposed improvement using the learning process defined within the AI Operating System.
- Do not modify approved governance documents without Founder approval.

---

# Design Philosophy

AskPIP does not rely upon AI memory.

AskPIP relies upon governed knowledge.

Every repeated Founder correction should be treated as evidence that the AI Operating System can be improved.

The repository is the authoritative source of truth.

Not the AI.
